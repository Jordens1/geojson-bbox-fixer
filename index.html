How to fix a GeoJSON bbox mismatch

  1. Paste your GeoJSON, choose a file, or select Load an example.
  2. Select Inspect bbox values. Each result identifies the feature, geometry, or collection that declares the box.
  3. Review the differences. Copy an individual calculated bbox, or fix all mismatches together and download the repaired GeoJSON.

File limits and privacy

Your browser reads and processes the file locally. The checker accepts up to 5 MiB, 200,000 positions, and 64 levels of JSON nesting. A download creates a separate file.

Supported coordinates

Use WGS84 longitude and latitude, with optional elevation. All positions in a file must use the same number of dimensions. The checker handles geometry already split at the antimeridian.

When to keep the declared bounds

A broader box may intentionally cover an entire survey area. Keep it if downstream users rely on that coverage. Repair changes bbox metadata only. Coordinate conversion and polygon topology need separate checks.
